# Sauce & Spoon: Tabletop Menu Tablet Pilot Project

> A project management portfolio piece: planning, executing, and closing a tablet-based ordering pilot for a scratch-to-table restaurant chain.

---

## Overview

Sauce & Spoon is a local restaurant chain specializing in scratch-to-table cuisine. To support its annual growth goals, the company wanted to test tabletop menu tablets that let guests browse, order, modify orders, and pay on their own, before committing to a full-scale rollout.

This repository contains full project lifecycle documentation for the pilot, from the evolving project charter through stakeholder analysis, scheduling, test-launch findings, closeout, and personal reflection.

**Role:** Project Manager

**Pilot locations:** Sauce & Spoon North and Downtown (bar areas only)

**Launch date:** April 23 (Q2)

**Methodology:** Hybrid (traditional planning + agile iteration during the test launch)

---

## Project Goals

| Goal | Target |
|---|---|
| Reduce average table turn time | ~30 minutes |
| Increase average daily guest count (pilot bar location) | +10% |
| Reduce food waste via improved order accuracy | -10% |
| Increase average check value | +15% ($65 to $75) |
| Reduce order errors through guest self-ordering and modification | n/a |
| Improve the ordering and payment experience | n/a |

### Scope

**In scope**
- Implement tablet ordering at the North and Downtown pilot **bar** locations
- Configure and integrate with existing software and POS workflows
- Collect and analyze operational and customer data against predefined metrics

**Out of scope**
- Rollout across all Sauce & Spoon locations
- Upgrading existing systems for enterprise-wide implementation
- Non-bar dining areas at the pilot locations

---

## Methodology

The project used a **hybrid approach**:

- **Traditional (waterfall) planning** for hardware setup, staff training, resource allocation, and system/POS integration planning.
- **Agile practices during the test launch**, with real-time stakeholder and customer feedback driving iterative improvements to the tablet interface, workflows, and staff training.

### Test Launch Customer Survey (n = 50)

| Finding | Result |
|---|---|
| Overall tablet rating of 4 or 5 | 72% (40% Good, 32% Great) |
| Waiter instructed them "very well" on tablet use | 76% |
| Navigation rated Fairly/Very easy | 48% |
| Kitchen prepared the order correctly | 72% |
| Confident/very confident paying via tablet | 66% |
| Signed up for the newsletter on the tablet | 78% |
| Preferred tablet exclusively | 40% |
| Wanted a mix of tablet and waiter | 30% |
| Reported a technical issue during the visit | 12% |

### Issues Identified and Corrective Actions

| Issue found in pilot | Action taken |
|---|---|
| Confusing tablet navigation | Simplified the user interface |
| Payment confusion (e.g., cash-only guests) | Clarified payment options on screen and in staff training |
| Order accuracy errors in the kitchen | Improved waitstaff-to-kitchen communication and kitchen order verification |
| Tablet freezes | Introduced a pre-service tablet testing checklist |
| Inconsistent guest onboarding | Additional waitstaff training on guiding customers and pacing |

## Lessons Learned

1. **Expect the unexpected.** The pilot surfaced issues with navigation, payments, order accuracy, and tablet reliability. Flexibility and quick corrective action kept the project on track.
2. **Communication drives success.** Regular coordination between the project manager, general managers, waitstaff, kitchen staff, and technical teams resolved issues quickly.
3. **Change management needs sustained support.** Additional staff training and reinforced procedures were key to adoption and to reducing table turn time.
4. **Let data drive decisions.** Customer surveys and performance metrics guided continuous improvement.

---

## Next Steps and Handover

- **Maintenance:** The IT vendor maintains the system under the existing hardware subscription; restaurant staff continue pre-service tablet checks.
- **Future rollouts:** Expand to all Sauce & Spoon locations using the lessons learned for standardized training, staff readiness, customer communication, and performance monitoring.
- **Post-implementation evaluation:** Verify that expected benefits are sustained over the long term.
- **Ownership:** Responsibility for future tablet rollouts transfers to **Molly Edwards**, with full documentation, lessons learned, operational procedures, and maintenance guidelines.
